R36S rhythm machine, as an ArkOS Port

Install: copy Rhythm.sh and the rhythm folder into the ports folder on the SD card
(ArkOS: the EASYROMS partition, folder "ports"; on a two-card R36S it may be the second card).
Then on the R36S: Ports > Rhythm.

Leave: hold SELECT + START for a second and a half.
If something is wrong, rhythm/log.txt and rhythm/stdout.txt say what happened.
